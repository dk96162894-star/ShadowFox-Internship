# ShadowFox Internship - Task 1

## Python Programming Tasks

This task contains Python programs based on variables, numbers, lists,
if conditions, and for loops.

## Topics Covered

### 1. Variables
- Check the data type of `pi = 22/7`
- Understand why `for` cannot be used as a variable name
- Calculate Simple Interest

### 2. Numbers
- Use the `format()` function
- Calculate the area of a circular pond
- Calculate the amount of water in the pond
- Calculate speed in meters per second

### 3. List
- Perform operations on a Justice League list
- Add and remove members
- Change the position of members
- Replace and sort the list

### 4. If Condition
- Calculate BMI category
- Identify the country of a city
- Check whether two cities belong to the same country

### 5. For Loop
- Simulate rolling a six-sided die
- Count occurrences of 6 and 1
- Count two consecutive 6s
- Simulate a 100 jumping-jack workout
